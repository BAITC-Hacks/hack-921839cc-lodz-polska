# AGENTS.md

## Overview

This repository contains the project for the LODZ POLSKA hackathon.

## Guidelines

- Read the existing code and documentation before making changes.
- Keep changes focused on the requested task.
- Follow the existing project structure and coding conventions.
- Do not remove or rewrite working code unless necessary.
- Update documentation when behavior or setup instructions change.
- Avoid committing secrets, API keys, passwords, tokens, or other sensitive data.

## Validation

Before considering a change complete:

1. Run the project's available tests or checks.
2. Verify that the changed functionality works as expected.
3. Report any checks that could not be run and why.

## Git

- Use clear, descriptive commit messages.
- Do not force-push or rewrite shared history unless explicitly requested.
- Keep unrelated changes out of commits.
